# {{PROJECT_NAME}}

A [Sinwan](https://sinwanjs.com) + JavaScript app built with Vite, [vite-plugin-sinwan](https://github.com/sinwanjs/vite-plugin-sinwan) and Tailwind CSS. The demo uses `sinwan-router` with Home, About, and Contact pages.

To install dependencies (or use npm, pnpm or yarn):

```bash
bun install
```

To start the dev server with hot module replacement:

```bash
bun run dev
```

To build for production into `dist/`:

```bash
bun run build
```

To preview the production build locally:

```bash
bun run preview
```
